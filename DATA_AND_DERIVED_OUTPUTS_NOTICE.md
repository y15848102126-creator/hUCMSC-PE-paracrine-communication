# Data and derived outputs notice

This candidate includes project-authored configuration files, aggregate statistics, classifications, provenance fields, and selected derived summary tables. It excludes raw/public expression matrices and complete third-party data resources. Complete MSigDB memberships were reduced to names, versions, collection identifiers, sizes, SHA-256 hashes, and source URLs. Absence of a source table from this archive is a redistribution boundary, not evidence that the source data do not exist.

Human review is required before choosing any license for derived tables. Users must follow the terms of each original data or database provider.
